# Glossary

| Term | Meaning |
|---|---|
| AMT | Adaptive Metadata Tree. The v4 metadata structure that replaces the manifest list; enables single-file commits. |
| DV | Deletion vector. A bitmap of deleted row positions for a data file (v3). |
| Equality delete | A delete file that removes rows matching column values. New writes are forbidden in v4. |
| MV | Materialized view. |
| PMC | Project Management Committee of an Apache project. |
| RC | Release candidate, the build a release vote is held on. |
| REST catalog | The HTTP catalog protocol defined by `open-api/rest-catalog-open-api.yaml`. |
| RM | Release manager. |
| Spec | The table format specification in `format/spec.md`; versions v1 to v3 are released, v4 is in design. |
| Sync | A recurring working-group video meeting. |
| Variant | A semi-structured data type added in v3; "shredding" stores parts of it as typed columns. |
| Binding vote | A vote cast by a PMC member. Only binding votes count toward the result. |
