## Highlights: Python, Rust, Go and C++

PyIceberg improved add_files duplicate checking, added REST pagination and page-size support for listing, a View object API, and RecordBatchReader support in append and overwrite. Iceberg Rust added public API checks in CI, workspace publishing, the EncryptionManager step of its encryption work, a FastAppend fix for delete-only manifests, and custom Runtime support in catalogs (breaking). Iceberg Go improved its CLI, added golden round-trip tests, row lineage preservation in copy-on-write rewrites and non-shredded variant support. Iceberg C++ added a MergingSnapshotUpdate base, position delete coalescing, a Puffin reader and writer, nanosecond timestamp types and a merge-on-read delete filter.
