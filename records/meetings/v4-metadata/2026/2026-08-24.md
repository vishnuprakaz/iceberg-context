## V4 write code path and a new UpdateFiles interface

Ryan's question or idea was a V4MergingSnapshotProducer, which raises whether V4BaseRowDelta and V4BaseOverwriteFiles are needed alongside it. The proposal is a new UpdateFiles interface that merges RowDelta and ColumnUpdates, so that one interface allows different update strategies for data files (merge-on-read, column overlay). Separate interfaces do not work well when a DML has to commit both data DVs and column files in one snapshot. An open point is whether UpdateFiles should also cover OverwriteFiles for the copy-on-write strategy, since all three map to the overwrite operation type.

**Open questions:**
- Are V4BaseRowDelta and V4BaseOverwriteFiles needed alongside a V4MergingSnapshotProducer?
- Should the new UpdateFiles interface also encapsulate OverwriteFiles for the CoW update strategy?
