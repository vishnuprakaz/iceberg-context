## UTF-8 sort order correctness fix

Iceberg's string sorting uses Java's UCS-16 order (as the notes put it), which can differ from the correct UTF-8 byte order for supplementary characters. The decision was to implement the UTF-8 byte order fix without a backward compatibility fallback, on the reasoning that the difference only affects rare supplementary characters such as emojis, so the change is non-breaking for existing data. Neelesh will prioritize it for 1.12.

**Decisions:**
- Implement the UTF-8 byte order fix without a backward compatibility fallback.
