## Summary

The Spark Community Sync notes for 11 November 2026 list merged work, including Iceberg field IDs exposed as DSv2 column IDs in Spark 4.2, geometry bounds in Parquet writers, iterative runtime filtering with PartitionPredicate, and a fix to CBO column statistics. Five discussion points are framed as decisions to make, with no outcomes recorded: a freeze date and branch for 1.13; whether to cut 1.12.1 for two silent-data-loss fixes; what gates publishing Spark 4.2 support; whether to skip, add or certify against Spark 4.3; and owners for a set of wrong-result bugs. A list of review requests closes the notes.

## Highlights: recently merged

Merged for DSv2: Iceberg field IDs set as Spark column IDs so that Spark 4.2 column-ID validation works for nested fields, a parser forwarding fix so CREATE FUNCTION with parameters works with the Iceberg SQL extensions (backported to 4.0 and 4.1), and rethrowing ValidationException from REST 400 responses. Writers now emit geometry bounds in Parquet, and writing variant to ORC fails with a clear error. Reads gained iterative runtime filtering with PartitionPredicate, a fix for unprojected shredded variants in vectorized reads, and scan-schema based CBO column statistics. A per-task scanDuration metric landed for 4.1 with a 4.2 port open.
