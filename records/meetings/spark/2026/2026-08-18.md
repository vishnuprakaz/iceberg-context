## Shared Spark source proof of concept

The problem is that every Spark minor version is a full copy of the spark/ tree: the 4.2.0 pull request is several hundred files and over 100k lines, and SPARK-54633 proposes quarterly Spark minors, so this would happen about four times a year. The proof of concept, discussed on the dev list, has 555 shared files against 73 to 74 per-version shim files, 88% shared, with the full suite of about 17,800 tests shared and only version-specific expectations shimmed.
