## Shared Spark source: new proof-of-concept approach

A new approach for the shared Spark source work on the dev list drops the shim layer. spark/common/ holds only files that are byte-identical across member versions, and divergent files stay as full per-version copies. A build check fails on duplicate classes and on identical copies that belong in common/, and version strings in comments are neutralized so more files match. Each version still builds its own runtime jar from common/ plus its own directory, so artifact names and coordinates do not change.
