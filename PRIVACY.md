# Privacy

This repository describes a public open-source community. It holds only information that is already public and that concerns
project activity.

## What is recorded about people

- GitHub login, display name and Apache ID.
- Public project roles (PMC member, committer, release manager) and the dates they began.
- Public project activity: pull requests, reviews, mailing-list posts, votes, proposals, talks, participation in recorded meetings.

## What is never recorded

- Email addresses, phone numbers, home or work addresses.
- Personal life, health, family, or anything not related to the project.
- Guesses about motives, character or private relationships.

## Labels

Statements are labeled by how they were obtained: `observed` (straight from data), `extracted` (taken by an AI model from a cited
source) or `inferred` (an AI judgment, such as who is speaking in a transcript without speaker names). Inferred statements can be wrong.

## Corrections and removal

If something about you is wrong, or you want it removed, open an issue with the **Privacy request** template or contact the
maintainer through their GitHub profile. Requests are handled promptly and the pipeline is configured so the content does not return.
