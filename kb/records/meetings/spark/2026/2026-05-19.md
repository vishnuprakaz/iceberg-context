## Summary

The Spark sync notes list highlights: shredded variant writes in Spark 4.1 with a 4.0 backport, migrations to newer DSv2 interfaces, disabling min/max aggregate pushdown for string and binary, and bug fixes. Review was requested for RewriteTablePath fixes, CALL older_than with function expressions, and three sort-related PRs. The main discussion topic was the Spark version strategy after 1.11: Spark 3.4 is removed with that release, and the proposed matrix keeps 3.5 and 4.1, removes 4.0 and adds 4.2, with a list of new Spark 4.2 features relevant to Iceberg. Spark CI improvements were also on the agenda. The notes record proposals without a stated decision.

## Highlights

Spark 4.1 gained support for writing shredded variant, with a Spark 4.0 backport. DSv2 upgrades migrated SparkWriteBuilder to SupportsOverwriteV2, RollBackStageTable to SupportsDeleteV2 and SparkCopyOnWriteScan to SupportsRuntimeV2Filtering. Min/max aggregate pushdown was disabled for string under any mode and for binary. Bug fixes covered a ThreadLocal leak in CommitMetadata, FileIO path and length passthrough, and an NPE in RemoveOrphanFiles with prefix listing.

## Spark version strategy after 1.11

With the 1.11 release Spark 3.4 is removed, and the notes say in-flight Spark 3.4 PRs should be pinged or closed. The proposed matrix keeps Spark 3.5 as the single 3.x line, removes 4.0, keeps 4.1 and adds 4.2. New Spark 4.2 features listed include the SupportsReportOrdering interface, sort elimination via DSv2, K-way merge for sorted reads, a CDC connector API, CREATE TABLE LIKE for V2, enhanced partition stats filtering and PartitionPredicate in metadata-only delete. The notes present the matrix as a proposal and record no decision.
